# Archive

Legacy files from the original hand-rolled version of laurenleppert.com,
kept for reference only. **Not part of the build** — Eleventy's input is `src/`
and these are never copied into `_site/`.

- `styles.css` — original single stylesheet (superseded by `css/base.css` + `css/landing.css`)
- `script.js` — original page script
- `theme.js` — original theme toggle (the live version lives at `js/theme.js`)

Safe to delete once you're confident nothing here is worth salvaging.
